# Security Policy

## Reporting a concern

If you discover a security or privacy issue, please do not publish exploit details or personal information in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer privately through the contact method listed on their GitHub profile.

## Scope

This is a static browser-based project. It does not currently provide a project-specific backend, account system, or server-side data store.

Please do not submit secrets, API keys, passwords, or private user information in issues, screenshots, or pull requests.
